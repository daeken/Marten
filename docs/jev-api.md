# Direct Jev wire contract

Sources: TypeSafe's [System One reference](https://docs.typesafe.ai/api/system-one), [OpenAPI](https://api.typesafe.ai/openapi.json) (3.1, info version 0.2.0), [Choice](https://docs.typesafe.ai/primitives/choice), [images](https://docs.typesafe.ai/images), [models](https://docs.typesafe.ai/models), and [errors](https://docs.typesafe.ai/api/errors). The wire client does not enroll keys or make key-validation calls. No inference request was used to verify the docs.

- The only implemented operation is `POST https://api.typesafe.ai/v1/systemone`, fixed to `jev-1.14.0`. The trusted caller provides a console-issued `Authorization: Bearer <key>` value independently of the prepared request. No caller URL/model/headers, redirects, proxies, cookies, or resends. One fresh HTTP/1.1 connection, no reuse or reconnect. A timeout may still leave a completed/billed upstream operation.
- Text uses UTF-8 JSON with `model`, string `state`, and `questions` containing one host-named entry (`q1`) with `type`, `instructions`, and optional Noul or required Choice `criteria`. The API accepts structured state/instructions as well; the client intentionally does not expose arbitrary JSON. Noul returns `noul` (probability of yes), not a verdict. Choice returns `choice`, `confidence`, and per-label `probabilities`. `JevRequest.Decide` supplies exactly `yes`, `no`, `need more information`, and `undecidable` as Choice keys with distinct descriptions. These keys are not a provider enum; low confidence never changes the selected label.
- For preview, `JevPreviewImage.Stage` requires explicit opt-in and already-prepared RGB/RGBA PNG bytes. The provider also advertises JPEG and base64; this client only sends a conservative PNG subset (non-interlaced 8-bit, no ancillary chunks). It checks dimensions, chunks and scanline bounds and regenerates the compressed stream. No URL, path, filename, or original metadata reaches the caller interface. Per the image guide, send multipart with first part `request` (`application/json`), then a unique `image/png` file part. The JSON has `assets[generatedPlaceholder] = {type:"image",part:"image1"}` and one placeholder use in `state.image`, not in an object key. Set `TypeSafe-Danger-Zone-Images: true` only for that request. The guide marks images not production-ready; the client never enables long context.
- Tighter limits than the service: 12,000 UTF-8 bytes of state, 2,000 of instructions, two through eight Choice labels (64 bytes each) and 1,024 bytes per criterion. At most one image, 280–1024 px per side, at most 1 MiB before and after staging. Wire body ≤ 1 MiB + 32 KiB; response headers and JSON body each capped at 16 KiB; default 20-second request/body deadline. `200` must yield the pinned model, one matching answer/type, finite unit-interval scores, a Choice distribution with exactly the submitted keys and a selected maximum, and bounded nonnegative integer `usage.input_tokens` and `usage.output_tokens`.
- `JevException` carries only a fixed kind, optional HTTP status and bounded `RetryAfter` hint (never used to retry). HTTP 400/413/415/422 are input errors, 401/403 auth errors, 3xx redirects, 429 rate limit, 5xx (including 529) unavailable. Nonstandard success, invalid bodies, transport failures and timeout/cancellation are separate from labels. No provider body, arbitrary header, raw exception, key, or payload is included in diagnostics. Public docs show organization-specific quotas and enterprise ZDR, but do not establish this account's scopes, retention, residency, or idempotency.

## Marten tool

`jev` accepts `mode` (`decide`, `choice`, or `noul`), explicit string `state` and `question`, `options` (two to eight `{label, description}` entries for `choice`), and optional `image_artifact` (a same-agent published PNG ID). No other context is attached. Text can be agent-composed; the operator's global opt-in covers ordinary tool paths including PowerShell. No per-call grant. PowerShell, including in-turn PowerShell, schedules and manual replay do not borrow a model view, so uncertainty evidence is unavailable there. In an admitted view, one local lexical pass can return up to three `(seq, start, length)` UTF-16 references only; matches are search leads, not additional decisions. No second outbound call.

Try `decide` to check whether release notes meet explicit acceptance criteria or whether needed facts are missing, `choice` to compare two proposed approaches against a rubric, or `noul` to estimate whether supplied evidence supports a claim. Use the answer as judgment, not proof. Marten never invokes it automatically.

A validated verdict remains private until the consumer accepts it against the current settings generation. Retirement before acceptance withholds it; retirement afterward does not recall the accepted handoff. Agent publication remains subject to turn cancellation and evidence visibility. No settings lock spans a send, append, or publication.

Dispatch caps concurrency at four. The usage ledger reserves the maximum at the pinned rate (default $0.042 per million input tokens, output free) before each send against existing `jev` and `total` budgets when configured. It reconciles once on a validated answer; transport failure or interruption can leave an unknown call and its conservative reservation for that day. The existing usage ledger records counts and summed latency for validated replies, plus fixed-label counts for `decide` only—no payloads, option labels, evidence, or keys in these metrics. No automatic retries. No #26 policy is implemented here.
