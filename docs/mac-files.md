# Read-only Mac Files (native API)

Mac Files is **off by default**. The boot-time host setting `"macFilesEnabled": true` opts all active paired devices into browsing the Mac as the account running Marten. Use this only when you trust every paired credential with that account's readable files. A bearer is not physical-device attestation. Files may include private data, credentials, backups and agent/runtime state; revoking a device cannot recover a copy or invalidate separately usable credentials read from disk. There is no project grant or folder allowlist.

Requires non-root Marten on Apple silicon with macOS 26 or newer, and the [embedded tailnet HTTPS helper](embedded-tailnet.md) built from a revision that supports the Files startup handshake. The default-off setting retains the previous helper startup handshake. An older helper rejects the Files startup mode; there is no fallback to other HTTPS proxies. The canonical name must match TLS SNI and HTTP Host. The helper strips incoming proof headers, adds the private per-start proof only on Files requests received on that TLS listener, and forwards over loopback. Kestrel requires that proof and an active paired `Authorization: Bearer …` credential. A local web/operator session, outside-agent token, direct loopback request with the canonical Host, direct private HTTPS pairing without the embedded helper, or a forwarded header is not enough. No browser/PWA, outside-agent, or public Files route is added.

## Wire contract

All calls are `GET` under `/api/mac-files`; no query, `Origin`, `Range` or caller-supplied path. Only the server generates opaque handles. The JSON below uses placeholders for handles and time.

| Route | Successful response |
| --- | --- |
| `/roots` | `[{"id":"<directory handle>","label":"Mac"}]` for filesystem root `/`. |
| `/entries/{handle}` | `{"entries":[{"id":"<handle>","name":"example","directory":false,"bytes":123,"modified":"<UTC RFC3339>"}],"next":"<cursor>"}`. Accepts a root, directory, or cursor. `bytes` is absent or null for directories; `next` is absent or null on the last page. |
| `/bytes/{handle}/text` | Exact prefix `min(observed size, 256 KiB)`. No encoding check or conversion. |
| `/bytes/{handle}/raster` | Entire observed file, at most 8 MiB. No decoding or media-type inference. |
| `/bytes/{handle}/share` | Entire observed file, at most 32 MiB. No conversion or server-side export. |

All successful byte responses use `application/octet-stream`, `Content-Disposition: attachment` (no filename), exact `Content-Length`, `Cache-Control: no-store` and `X-Content-Type-Options: nosniff`. JSON responses are also not cacheable. A client should discard incomplete transfers and not trust file contents as executable or rendered markup. There is no write, auto-export, archive, preview execution, indexing, or content spool. Read-only means no intentional write to the source filesystem; reads may update access time or cause ordinary OS/filesystem activity (e.g. automount, file hydration).

Hidden and physically mounted trees are eligible where macOS and the effective account allow access. Marten does not elevate or bypass POSIX permissions, macOS privacy controls, or sandboxing. Symbolic links are never followed. Finder aliases are not resolved; an alias file may appear as an ordinary file with its own bytes. Special files are skipped; known device/pseudo/automount filesystem types (`devfs`, `fdesc`, `procfs`, `autofs`), invalid or misleading names, and unrepresentable paths (over 1,000 UTF-8 bytes relative to root) are excluded. Scope is owner-trusted: same-UID processes, the admin and the local mount namespace are not adversaries this route isolates. Descriptor/revision checks reject ordinary replacements and changes, but do not offer a filesystem snapshot, detect every same-metadata mutation or remount, or make file opens immune to a hostile privileged concurrent device substitution or stalled filesystem.

Pages have at most 100 entries, directories first then ordinal name order, from one bounded scan (at most 2,000 directory entries). Pass `next` as the next entry handle unchanged. Handles are bound to the issuing credential and expire three minutes after issuance; a directory handle may refresh the same object, but cursors are tied to the original directory revision and position. File handles are tied to the observed file revision. Directory and cursor handles never read file bytes. Refresh on missing/expired/stale handles. Admission uses one in-flight Files operation per credential and four total with no queue or cross-credential reservation. Data staging is memory-only and bounded to at most 32 MiB per staged byte response. Catalogs are bounded to 2,200 handles and two retained directory snapshots per credential, 4,096 handles and eight snapshots globally. Expired entries are unusable and reclaimed on subsequent successful publication work. The 20 s application budget is cooperative around synchronous filesystem calls; an unresponsive filesystem may keep a slot until the syscall returns.

Typical failures are empty: `401` for a missing or invalid paired credential at the native authority; `403` for an inadmissible request or inactive credential at publication; `404` for disabled/unsupported Files or invalid, expired or wrong-type handles/purposes; `409` for replaced, changed or no longer readable content; `413` for an oversized scan or whole-file operation; `416` for ranges; `429` for admission or handle limits; `503` for a pre-publication deadline. Other routing/authentication failures can happen earlier. No success is sent until bounded staging completes and publication wins the same gate as authoritative credential removal. Revocation before commit denies publication. Revocation after commit aborts an active response; it cannot retract bytes already handed to the transport, delivered, or saved by the client.

## Scratch validation

Run `dotnet test tests/Marten.Tests --nologo -v:q -m:1 --filter FullyQualifiedName~MacFilesTests -- RunConfiguration.MaxCpuCount=1 xUnit.ParallelizeTestCollections=false`. To include the real loopback TLS proxy-to-Kestrel control on supported Macs, build the Go test binary to a private temporary directory (`go test -tags 'ts_omit_logtail ts_omit_oauthkey ts_omit_identityfederation ts_omit_peerapiserver' -c -o /absolute/private/temp/proxy-fixture` from `src/Marten.Tsnet`) and set `MARTEN_MAC_FILES_PROXY_FIXTURE` to that binary for the .NET command. The fixture uses a synthetic certificate and isolated scratch homes, not a real tailnet or an installed helper.
